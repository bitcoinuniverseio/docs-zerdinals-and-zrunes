# Security

## Reporting a vulnerability

If you believe you have found a security problem in the product at
zrunes.io, in its public API, or in anything this documentation describes,
report it privately:

1. Use GitHub private vulnerability reporting on this repository
   (Security tab, "Report a vulnerability"), or on the product organization
   `bitcoinuniverseio` if the issue is in the product itself.
2. Include what you found, where, the impact you believe it has, and steps
   to reproduce. A proof of concept helps; destructive demonstrations do
   not.

Do not open a public issue for a vulnerability, and do not test against
other people's assets: everything on this chain is real and irreversible.

## What to expect

You will get an acknowledgement, an assessment of the report, and credit in
the fix's release notes if you want it. There is no bug bounty program at
this time; this file will change if that changes.

## Scope notes

- Documentation-only problems (a wrong claim, a misleading instruction that
  could cause loss) are security reports too; a doc that tells someone to
  do something unsafe is a vulnerability here.
- The protocols themselves are specified in the product repository; a flaw
  in a specification is best reported privately as above.
