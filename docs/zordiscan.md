# ZordiScan

ZordiScan is the first-party explorer for Zcash digital artifacts. It reads only from Universe-operated Zcash infrastructure.

One search field accepts a block height, block hash, transaction id, transparent address, Unified Address with a transparent receiver, Zerdinal id or number, ZRune id or name, collection slug, or content hash.

Every page offers a friendly view, a protocol view, and a raw view. Status information (node height, indexer height, lag, mempool state) is always shown honestly; stale data is labeled stale.
